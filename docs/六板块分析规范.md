# 六板块分析规范

本文是公开项目的唯一学科分析规范。`AGENTS.md`、`CLAUDE.md` 和 CodeBuddy 项目规则只负责把智能体路由到这里，不复制另一套合同。机器校验字段见 `config/content_contract.json`，模板见 `templates/`。

## 一、适用模式

### 整卷

先确认真实板块、题号、分值和答案页，再生成一份整卷总览及本卷实际存在的板块详案。不得因为模板有六份就虚构缺失板块，也不得沿用其他试卷题号、分值或答案。

### 单板块

只交付对应板块的独立 Markdown 与 Word。文件自身必须写清材料、题号、答案、证据、方法、误区和迁移，不以“见总览”省略关键内容。

### 答案缺失

继续完成文本分析和暂定题解，但统一标记为【文本推导】。不得冒充正式答案、评分标准或官方分值；写明证据、答案边界和等待裁决之处。

## 二、证据与保真

证据优先级：清晰题面及正式答案页面；经复核的提取稿；试题原文上下文；经核验的教师讲解；教材、原著和权威公开资料；OCR、转写和一般网络材料只作定位辅助。

分析前必须核对材料类型、页序、题号、选项、注释、分值和答案归属。OCR 与页面冲突时回看页面；手写圈画默认不是题面。外部事实无法可靠核定时，不编造年份、地点、人物关系、典故或引语。

正式详案始终分层：

- 【官方评分参考】：经正式答案或评分标准支持的结论、分值、要点和允许边界。
- 【文本推导】：题干拆解、原文定位、关系判断、答案生成和争议辨析。
- 【教学拓展】：背景、课堂追问、变式和迁移条件，不作为唯一评分答案。

## 三、通用分析闭环

每道题遵循“题面保真—文本建模—逐题取证—评分对齐—失分诊断—课堂迁移”。

选择题对 A、B、C、D 每项分别写：原文位置、选项改写、正误判断、设误类型。主观题写：审题、证据或定位、关系或整合、评分点、参考答案、失分诊断。重点题还要说明可接受替代表达、不可省略信息、越界表述、多解条件与裁决依据。

不得用术语堆砌代替分析。每个手法或方法都要连接“具体文本—实际作用—适用条件”。基础题完整而简洁；证据链长、答案有争议、多评分点、OCR 不确定或迁移价值高的题自动加深。

## 五、阅读一：信息类与非连续性文本

1. 说明每则材料的来源属性、文体、信息功能、选材特点、时代价值和组合逻辑。
2. 逐自然段标出关键词、核心概念、事实与观点，概括段意；显式区分名称、概念、客观实体和分类类型。
3. 划分单篇和组合文本层次，梳理信息展开或论证路径。
4. 比较多材料的共同点、差异、互补、互证或张力。摘要、图表、问答和改写稿也作为复合文本，检查删、增和关系变化。
5. 总结作者立场与结论边界，不把“可能、主要、几乎”等有限判断绝对化。
6. 全部选择题逐项取证；主观题展示从任务限定、材料分类到评分点表达的完整链条。
7. 迁移方法须区分新闻、评论、科普、图表和多材料文本的适用条件。

## 六、阅读二：文学类文本

1. 核验作者、出处、注释与背景，只保留有助于理解选文的内容。
2. 逐段批注关键词句和重点段落的上下文含义。
3. 梳理情节、人物心理和关系变化、结构转折，保留人物心理的反复，不强写成单线成长。
4. 人物特征必须由语言、动作、心理、神态、环境、细节或关键选择作证。
5. 分析主旨、情感、写作意图、价值取向与时代意义。
6. 分析叙述视角、结构、语言、细节、多感官、象征、对比、衬托、反复、伏笔等，写清文本内容、具体手法、实际效果。
7. 关键段落从内容、结构、人物、主题、艺术效果五维分析；不适用的维度说明原因。
8. 先用反复语气、动作节奏、结构转折和结尾校准整体声调，再判断局部手法；跨文本题使用同一比较维度。

## 七、阅读三：文言文

1. 按原文顺序逐句处理，不跳过简单句。
2. 注释实词、虚词、人物、官职、地名、制度和文化常识；重点词展开古今异义、通假、活用、一词多义、偏义复词和课内关联。
3. 逐句核查判断、省略、被动、定语后置、状语后置、宾语前置、主谓倒装和固定结构；无证据不贴标签。
4. 每句给直译、必要语序调整、补出的省略成分和语意说明，最后形成连贯全文翻译。
5. 梳理施事、受事、人物关系、转折、因果和先后；全文语境推翻初判时回改前题。
6. 完成断句、词义、常识、概括、翻译和探究的全部题解。
7. 翻译题单列原句、参考译文、采分词、句式采分点、易错点和允许边界。
8. 形成本文实词、虚词、句式和课内关联迁移清单；全文讲评可采用“设题采分—回到全文”的两遍式。

## 八、阅读四：古诗文

1. 核验作者、背景、时代、题材、体裁、题注和注释；背景不详时不虚构。
2. 注释重点字词、意象、物象、声音、动词、时空词、情感词与可确指典故。
3. 每句先做语意翻译，再做内涵和艺术赏析；需要联读时说明句间关系。
4. 梳理画面、时空、感官、情感和结构转轴。
5. 炼字、意象、意境、虚实、动静、视听、色彩、对比、衬托、用典和比喻均须给诗句证据和实际效果。
6. 选择题逐项验证，主观题拆评分点、证据和表达边界；单一意象不能越界推出宏大主题。
7. 给整首综合赏析和适量同题材、同意象或同手法拓展，并说明不可机械迁移处。
8. 默写补出处、原作语境、易错字、理解性记忆方法和开放答案边界。

## 九、语言文字运用

1. 给语段分层并概括每层大意，说明话题推进和结构作用。
2. 分析语境、指代照应、语言风格、表达目的与上下文逻辑。
3. 每题展示判断和修改过程，不能只给最终答案。
4. 错别字说明字义、词义、固定搭配和语境证据。
5. 成语熟语说明对象、色彩、语体、搭配、功能、易混项和误用边界。
6. 语病写原句主干、病因、最小修改、完整新句和回填复查，尤其核对后一谓语的施事者。
7. 衔接题逐项核对话题、指代、逻辑、句式和语气，再通读完整语链。
8. 词语、比喻义或新词释义说明本义、语境义、变化方式和替换边界。
9. 文白转换先还原典故、隐喻和生僻词的直接语义，再按目标语体重建，复查原意、逻辑、语气和字数。

## 十、作文

1. 逐句拆材料和写作指令，解释关键词、关系词、隐含前提、情境、身份、任务与价值导向。
2. 分析各层内涵和层间关系，形成材料的核心问题。
3. 界定核心概念、成立条件、相关概念、反向追问、实践边界和偷换风险。
4. 给核心立意、最佳立意和多个可行立意，分别说明依据、优点与偏题、套作、窄化、口号化风险。
5. 提供实质不同的并列、递进、正反对照、问题解决、辩证关系、任务驱动或适合材料的叙事结构。
6. 每种结构写标题或适用题、中心论点、三个以上分论点、段落任务、段间推进、反面或边界分析、结尾落点。
7. 按历史、文化、科技、社会生活、青年成长、文学作品等分类论据。
8. 每则素材写事实摘要、可靠来源、适用角度、论证用法、与分论点连接、使用边界和避免生硬套用的方法；不编人物、数据和引语。
9. 提供标题库、开头、过渡、结尾、语言提升、完整提纲和必要示范段。
10. 事实真实、概念准确、逻辑清楚、语体适切优先于华丽表达；不能用单篇范文替代训练链条。

## 十一、课堂交付与迁移边界

每个板块都要转化为可执行的讲解顺序、关键追问、学生可能卡点、答案表达示范和迁移条件。只有任务、证据组织、设误方式、评分逻辑或文本结构至少两个核心维度高度一致，且能说明相同、不同和不可机械迁移处时，才增加跨试卷对照。

内容完成后先运行校验，再构建 Word，最后人工逐页验收；完整流程见[自动流水线说明](自动流水线说明.md)与[Word 生成与版式验收](Word生成与版式验收.md)。

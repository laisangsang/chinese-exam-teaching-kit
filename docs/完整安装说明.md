# 完整安装说明

## 基础要求

- Python 3.11 或更高版本。
- 能创建虚拟环境并从本地源码安装。
- 核心 Python 依赖：`python-docx` 与 `pypdf`，由项目元数据安装。
- 开发依赖：`pytest` 与 `build`，通过 `.[dev]` 安装。

项目当前不宣称已发布到 PyPI。公开仓库发布后，授权克隆目标为 `https://github.com/laisangsang/chinese-exam-teaching-kit.git`；当前请在已有源码目录中安装。

## macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
cekit doctor --report
```

开发环境：

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

## Windows PowerShell

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
cekit doctor --report
```

开发环境：

```powershell
python -m pip install -e ".[dev]"
python -m pytest -q
```

如果执行策略阻止激活脚本，可在当前终端临时采用组织允许的策略，或直接使用虚拟环境内的 Python；不要关闭整台机器的安全策略。

## 能力等级

`cekit doctor` 只检查本地状态，不联网、不安装工具、不下载模型。

| 报告项 | 等级 | 用途 |
| --- | --- | --- |
| `python` | core | 运行 CLI |
| `word` | core | 生成 DOCX |
| `pdf_text` | core | 读取 PDF 文字层 |
| `pdf_render` | enhanced | 把 PDF 页面渲染为图片，通常由 Poppler 的 `pdftoppm` 提供 |
| `ocr` | enhanced | 报告本地 Tesseract 命令是否存在；核心提取器仍需兼容的 `OcrProvider` |
| `video` | enhanced | FFmpeg 可用性 |
| `libreoffice` | experimental | 可用于本地 DOCX/PDF 转换和检查 |
| `swift` | experimental | macOS Apple Vision OCR 的运行条件之一 |
| `transcription` | experimental | 是否存在可选转写模块；流水线仍要求调用方注入本地转写器 |

“available”只代表找到模块或命令，不代表所有字体、语言包、模型与权限均已配置。

## OCR

有完整文字层的 PDF 不需要 OCR。扫描页或有效字符过少的页面需要页面渲染与 OCR：

- macOS：项目包含可选 `MacOSVisionOcr`，依赖本机 Swift 与 Apple Vision；它不上传图片。
- Windows / Linux：公开核心没有预置 OCR 后端。开发者应实现并注入 `OcrProvider`，同时提供本地 `Renderer`；可以使用组织批准的本地工具，但不要把材料发送到云端。
- 所有平台：不会自动安装语言包或下载模型。缺少能力时，先修复本地条件，或对已授权的页面进行人工校正。

## PDF 渲染与字体

自动提取的默认 PDF 渲染器查找 `pdftoppm`。Word 构建使用系统已有中文字体回退链，不捆绑字体文件。不同电脑的 Word 排版可能不同，因此必须在实际交付电脑上逐页验收。

## 音视频

默认 `LocalMediaProvider` 不包含转写模型。即使检测到某个转写模块，也不会自动选择、下载或调用它。若要处理新视频，开发者须注入本地转写器；画面提取器也是可选注入项。缺少 FFmpeg、转写器或画面提取器时，媒体阶段会记录 `degraded`，试卷分析仍可继续。

## 更新与卸载

更新本地源码后，在已激活环境运行：

```bash
python -m pip install -e .
cekit doctor --report
python -m pytest -q
```

卸载命令：

```bash
python -m pip uninstall chinese-exam-teaching-kit
```

卸载软件不会删除 `.local/`。其中可能含真实材料与成品，应由你根据本地备份和隐私制度决定保留或安全清理。

# 兼容性

本项目的核心要求是：智能体能在本地读取 Markdown、运行非交互命令，并把真实材料限制在 `.local/`。所有智能体都必须遵守[自动流水线说明](自动流水线说明.md)与[六板块分析规范](六板块分析规范.md)。兼容性会随客户端版本变化；以下是当前公开文档可确认的入口边界，而非对任意版本的保证。

| 工具 | 项目入口 | 使用方式 | 已确认边界 |
| --- | --- | --- | --- |
| Codex | `AGENTS.md` 与 [Codex 指南](../agent-guides/Codex.md) | 在任务中明确要求 Codex 先读取 `AGENTS.md` | 官方材料未确认其会自动加载本文件；须显式提出读取要求 |
| Claude Code | `CLAUDE.md` 与 [Claude Code 指南](../agent-guides/Claude-Code.md) | 项目根目录中的 `CLAUDE.md` 首行引用 `AGENTS.md` | Claude Code 文档说明支持项目记忆文件；仍应在任务中说明材料只能在本地处理 |
| WorkBuddy | [WorkBuddy/CodeBuddy 指南](../agent-guides/WorkBuddy-CodeBuddy.md) | 打开本地目录并手动引用指南 | 只作为手动参考入口；未核验其是否自动读取项目规则或支持原生 Skill |
| 腾讯 CodeBuddy | `.codebuddy/rules/project/RULE.mdc` 与对应指南 | 将项目规则目录随仓库一同打开 | 官方文档说明项目规则目录；具体客户端版本是否自动采用规则需在本机验证 |
| 通用命令行智能体 | [通用智能体指南](../agent-guides/通用智能体指南.md) | 粘贴可复制提示词并提供仓库路径 | 不依赖专有规则格式 |

Claude Code 的项目记忆机制见[官方说明](https://code.claude.com/docs/en/memory)。腾讯 CodeBuddy 的项目规则目录说明见[官方文档](https://cloud.tencent.com/document/product/1831/134362)。Codex 相关产品文档入口见[OpenAI 开发者文档](https://developers.openai.com/)；本项目不据此推定 `AGENTS.md` 会被自动加载。

## 本机核验

在开始真实任务前，先让所用工具复述它已读取的文件，然后执行：

```bash
cekit doctor --report
```

若智能体不能可靠读取上述入口或不能在 `.local/` 中工作，请改用通用提示词；不要把试卷、答案、音视频或教师材料复制到对话附件、云端工作区或公开仓库。

## 与系统能力的关系

- OCR、PDF 渲染和媒体章节学习取决于本机能力；详细条件见[完整安装说明](完整安装说明.md)。
- 缺少本地转写或画面工具时，媒体阶段会降级，试卷分析仍可继续；见[自动流水线说明](自动流水线说明.md)。
- 任何工具都不能绕过正式答案、三类证据分层、内容校验或人工逐页验收；见[Word 生成与版式验收](Word生成与版式验收.md)。

# 通用智能体指南

将下面整段提示词复制给具备本地文件与命令权限的智能体。先在仓库根目录工作；真实材料绝不离开 `.local/`。

```text
你正在协助处理高中语文讲评任务。先在项目根目录运行 `cekit doctor --report`，并读取本次任务的 `.local/tasks/原创练习/work_orders/analysis.md`、`docs/自动流水线说明.md` 与 `docs/六板块分析规范.md`。只在 `.local/` 中读取或写入真实试卷、答案、音视频、提取稿、任务内容和 Word 产物；禁止上传、粘贴、提交、推送或以任何方式把材料发送到外部服务。先核对题面、答案、分值与 OCR 不确定处，再按【官方评分参考】【文本推导】【教学拓展】三层写 Markdown 到任务 `content/`。完成分析前检索、逐题调用、完成后反向复核的知识审计；新发现只能作为 candidate。然后运行 `cekit validate --task .local/tasks/原创练习/task.json` 和 `cekit run --task .local/tasks/原创练习/task.json`；如需独立构建，使用 `cekit build --content .local/tasks/原创练习/content --output .local/tasks/原创练习/manual-output`。最后在本机人工逐页查看全部生成 Word 或其本地渲染结果，记录问题，必要时修改 Markdown 后重新构建；不得把 evidence_ready 说成视觉验收 passed。
```

## 操作顺序

1. 输入任务前，先让系统创建隔离空间：

```bash
cekit init --name 原创练习 --exam .local/inbox/原创练习.md
cekit run --task .local/tasks/原创练习/task.json
```

2. 智能体必须先读工作单和两份规范，再写 `content/`。工作单和题面优先于经验性方法；详案不复制其他试卷答案。
3. 每道题都保留题面证据、评分或推导边界、失分诊断与课堂迁移。没有正式答案时继续完成【文本推导】，但不冒充官方口径。
4. 完成后校验、构建、人工逐页复核。知识库只可辅助检索，不能覆盖本卷题面或正式答案；详见[知识库说明](../docs/知识库说明.md)。

## 不可跨越的边界

- 不上传材料、不调用外部大模型 API、不下载模型、不自动 Git 提交或推送。
- 不在公开 `content/`、`docs/`、`examples/`、`knowledge/` 或测试文件中写入真实材料。
- 不跳过材料核对、三类证据分层、六板块合同和人工视觉验收。
- 媒体工具缺失时如实记录降级并继续可完成部分；不虚构转写或画面结论。

更多命令与恢复行为见[自动流水线说明](../docs/自动流水线说明.md)，构建后验收见[Word 生成与版式验收](../docs/Word生成与版式验收.md)。
